# Wuselreich

Eigenständiges Aufbauspiel im Geist klassischer Wusel-Strategiespiele der frühen 90er:
Fahnen, Wege, Träger, Warenketten, Wachhütten und Ritter. Eine einzige HTML-Datei,
für Touch-Bedienung auf dem Handy gebaut (läuft auch am Desktop).

Starten: `index.html` im Browser öffnen. Der Spielstand wird im Browser gespeichert.

- Karte ziehen, mit zwei Fingern zoomen, Feld antippen zum Bauen
- Jedes Gebäude braucht einen Weg von seiner Fahne zur Burg; pro Wegstück ein Träger
- Holz → Bretter, Steine, Nahrung → Minen → Eisen/Gold → Werkzeug und Waffen
- Wachgebäude erweitern das Gebiet; Ziel ist die Eroberung der roten Burg
