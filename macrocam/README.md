# Macro RAW

Makro-Kamera-App fuer Android (entwickelt fuer Pixel 10 Pro XL, laeuft ab Android 12).

- Manueller Fokus bis an die Nahgrenze jeder Linse (Knopf "Nahgrenze")
- Focus Peaking (gruene Kanten = scharf) und Schaerfe-Wert
- Linsenwahl mit Anzeige von Nahgrenze und kleinster Bildbreite; ★ = staerkste Vergroesserung
- Dauerlicht, Ausloesen per Lautstaerketaste
- Ausgabe als DNG nach `DCIM/MacroRaw`

Installieren: `MacroRaw.apk` aufs Handy laden und oeffnen.
Bauen: `./gradlew assembleDebug` (Android SDK 35 noetig).
